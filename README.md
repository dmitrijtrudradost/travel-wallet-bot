# Мини-кошелёк путешественника
Версия 1.0

Telegram-бот на Python ведёт несколько путешествий: пара валют, курс и баланс. Курсы берутся только из [api.exchangerate.host](https://api.exchangerate.host) через `current_api.py`.

На текущем тарифе доступны ежедневный курс `GET /live`, история `GET /historical` и HTTPS. Конвертация `/convert` закрыта, поэтому суммы считаются локально по полю `quotes`. Базовая валюта ответа всегда USD, параметр `source` не передаётся.

## Запуск

Нужен Python 3.12.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env-example .env
python bot.py
```

В `.env` подставьте свой ключ ExchangeRate и токен от [@BotFather](https://t.me/BotFather). Файл `.env` в репозиторий не кладётся.

Данные бота пишутся в папку `data/`: база `wallet.db`, файлы истории `history_<id пользователя>.xlsx` и чеки в `data/receipts/`.

## Как пользоваться

При `/start` бот приветствует по имени и показывает меню. «Создать путешествие» спрашивает страну отправления и страну назначения, затем название поездки: его можно написать или выбрать из уже существующих. После этого бот запрашивает курс и уточняет, подходит ли он. Если нет, курс можно ввести вручную, как в обменнике. Затем бот просит стартовую сумму в домашней валюте и создаёт баланс в обеих валютах. Список поездок отсортирован по названию.

Одинаковые валюты допустимы, например RUB в RUB: курс равен 1.

Число в чате — расход в валюте страны пребывания. Бот показывает пересчёт, например `100.00 CNY = 1 280.00 RUB`, и кнопки «Да» / «Нет». После «Да» бот спрашивает тип расхода, затем фото или PDF чека. Чек можно пропустить. Сумма списывается, остаток показывается в двух валютах.

Кнопки меню стоят внизу, у поля ввода, и открываются кнопкой клавиатуры рядом со смайликом:

- Создать путешествие и Мои путешествия
- Баланс и История расходов
- Изменить курс

Под сообщением остаются только кнопки текущего шага: подтвердить курс, подтвердить расход, приложить чек, выбрать название или путешествие. Тип расхода и путь к чеку, если он есть, сохраняются в истории вместе с названием поездки. В файле Excel у такого расхода стоит ссылка «Чек». В истории можно выбрать название и увидеть только его расходы.

Те же действия доступны командами `/newtrip`, `/switch`, `/balance`, `/history`, `/setrate`.

История расходов хранится в SQLite и выгружается в xlsx: дата, время, тип траты и ссылка на чек, если файл приложен. У каждого пользователя Telegram свой набор путешествий.
